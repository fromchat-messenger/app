### Новые функции

- **Режим инкогнито:** при входе или на экране чатов можно войти в аккаунт, не оставляя
  следов на устройстве. Все данные хранятся в зашифрованном виде, ключ есть только в
  оперативной памяти, после закрытия приложения или выхода из аккаунта ключ и данные
  удаляются.
- **Настройка сервера:** кнопки "Проверить" и "Сбросить" убраны, теперь сервер 
  проверяется автоматически. Появилась карточка с режимом шифрования сервера.
- **Безопасность при смене режима шифрования:** при несоответствии режимов шифрования или
  при его явной смене с уведомлением потребуется повторная отправка всех сообщений, 
  отправленных до смены или меньше чем 5 сек. после нее для защиты от скрытой 
  подмены режима.
- **Улучшенный интерфейс меню "Больше"**: вместо стандартного меню из Jetpack Compose
  сделано кастомное с улучшенной анимацией.
- **Проверка сертификатов:** приложение больше не доверяет системныи сертификатам и
  при использовании официального сервера оно доверяет только Let's Encrypt. Если
  сертификат не в списке доверенных — появится предупреждение с возможностью все равно
  подключиться. Также блокируются потенциально небезопасные поддельные сертификаты известных инструментов мониторинга
  и фильтрации сети (например, UserGate).

### Сервер

- **Два режима шифрования на сервере:** легальный и E2EE. Можно переключать в CLI для 
  админов.
- Режим E2EE включен для всех на официальном сервере.
